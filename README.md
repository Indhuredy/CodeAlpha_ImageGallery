# 🖼️ Image Gallery Web Application

## 📌 Project Overview

The **Image Gallery Web Application** is a responsive and interactive web-based gallery developed using **HTML, CSS, and JavaScript**. The application allows users to view images in a structured gallery layout and open them in a lightbox view with navigation controls for an enhanced viewing experience.

---

## 🎯 Objectives

* Design a responsive image gallery layout using HTML and CSS
* Implement interactive image viewing using JavaScript
* Provide smooth navigation between images
* Enhance user experience with hover effects and transitions

---

## 🚀 Features

### Gallery Layout

* Responsive image grid layout
* Organized and visually appealing design
* Mobile-friendly interface

### Interactive Functionalities

* Lightbox image preview
* Next and Previous image navigation
* Close button for exiting lightbox view

### UI Enhancements

* Hover effects on images
* Smooth transitions and animations
* Responsive design for different screen sizes

## ⚙️ Working Principle

1. Images are displayed in a responsive grid layout
2. Users can click on any image to open it in lightbox mode
3. Navigation buttons allow users to move between images
4. JavaScript dynamically updates the displayed image

---

## ▶️ How to Run the Project

1. Download or copy all project files
2. Keep all files in the same folder
3. Open `index.html` in any modern web browser
